# Archived Python implementation

Paradox 1.9.4 is retained here for migration reference and history. The active release is **Paradox Native 2.0.1**, implemented in C++ under [`native/`](../../native).

Do not install this archived wheel alongside the native plugin. Follow the [current README](../../README.md), [installation guide](https://theninjallo.github.io/endstone-paradox/#/gettingstarted) and [migration notes](../../native/MIGRATION.md).

[`README-1.9.4.md`](README-1.9.4.md) preserves the old Python instructions and claims for historical reference. Its installation, UI, permissions, sensitivity and enforcement descriptions do not describe the native release.
